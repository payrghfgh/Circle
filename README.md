# ⭕ Circle - Customizable Radial Wheel Menu

**Circle** is a lightweight, customizable desktop overlay that activates a 6-slot radial wheel around your mouse cursor when you press your chosen hotkey.

---

## ✨ Features

- **Cursor-Centered Overlay**: Appears instantly around your cursor position with your mouse centered in the neutral hub.
- **6 Customizable Radial Slots**: 
  - Adjust System Volume (Volume Up, Volume Down, Mute).
  - Launch Applications or Files (`.exe`, documents, scripts).
  - Open Web URLs (e.g. Google, YouTube, GitHub).
  - Trigger Keyboard Shortcuts (e.g. `Ctrl+C`, `Alt+Tab`, `Media Play/Pause`, `Win+D`).
  - System Actions (Take Screenshot, Lock Screen, Task Manager).
  - Custom Shell / Command Line execution.
- **Customizable Global Hotkey**: Set any key combination (e.g. `Ctrl+Space`, `Alt+Space`, `Ctrl+Shift+Z`) or `Middle Click`.
- **Full Settings GUI & Live Preview**: Real-time visual wheel preview, color picker, emoji presets, and file browser.
- **System Tray Integration**: Quietly runs in the background with quick access to settings and test mode.

---

## 🚀 Getting Started

### Launching Circle
Double-click `run_circle.bat` or run:
```bash
python main.py
```

### How to Use
1. Press **`Ctrl+Space`** (or your custom shortcut) anywhere in Windows.
2. The 6-slot wheel appears around your cursor.
3. Move your mouse toward any slot to highlight it, then click to activate!
4. Click the center or press `Esc` to close without taking action.

### Customizing
- Double-click the **Circle icon in your System Tray** (bottom right of taskbar) or right-click it and select **⚙️ Settings & Customization**.
- Customize the shortcut key, slot names, icons, colors, and actions.
- Click **💾 Save & Apply**.
